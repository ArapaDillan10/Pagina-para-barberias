# 💈 Barber Studio - Website & Sistema de Reservas

Un sitio web moderno, elegante y responsivo diseñado para barberías profesionales. Cuenta con maquetación en tono oscuro, catálogo de servicios, galería de trabajos, testimonios y un módulo interactivo (Stepper) para la gestión de turnos online.

---

## 🚀 Estado Actual del Proyecto

Actualmente, el proyecto cuenta con el **diseño y maquetación UI/UX completados**, incluyendo:
- 🎨 **Diseño Oscuro (Dark Theme):** Estilo moderno con tipografías monoespaciadas (`JetBrains Mono` e `Inter`) y detalles visuales en tonos rojo y azul.
- 📱 **Diseño Responsivo:** Adaptado completamente a dispositivos móviles y pantallas grandes.
- 🧭 **Barra de Navegación Sticky:** Con enlace rápido a secciones clave.
- ✂️ **Sección Hero:** Con estadísticas, llamados a la acción y maquetación dividida.
- 💈 **Catálogo de Servicios y Productos:** Presentación clara de precios y descripciones.
- 📅 **Stepper de Reservas (UI):** Interfaz paso a paso para la elección de barbero, fecha, horario y confirmación de datos del cliente.
- 📸 **Galería y Reseñas:** Espacio estructurado para fotos del local y testimonios de clientes.
